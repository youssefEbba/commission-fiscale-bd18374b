# AGENTS.md — décisions techniques du projet

- Lignes de tableau cliquables : utiliser `ClickableTableRow` (`src/components/ui/clickable-table-row.tsx`) avec un vrai `<Link>` sur la colonne de référence — le composant ignore les clics venant des boutons/liens/menus de la ligne, donc les actions existantes n'ont pas besoin de `stopPropagation` ajouté à la main.
- Boutons « Retour » des fiches : utiliser le hook `useSmartBack(fallback)` (`src/hooks/useSmartBack.ts`) — revient à la page précédente si l'historique vient de l'application, sinon retombe sur la liste ; ne plus écrire `navigate(-1)` ou `navigate("/liste")` en dur dans les fiches.
- Alertes d'échéance des conventions : calcul centralisé dans `src/lib/conventionEcheance.ts` (seuils 90 j / 30 j, constantes nommées) — ajuster les seuils là, pas dans les pages.
- Permissions métier : passer par `hasPermission(...)` du `AuthContext` (JWT d'abord, repli `ROLE_PERMISSIONS`) — ne pas reproduire de règle métier par rôle dans les pages.
- Création de comptes : passe uniquement par la demande de rattachement publique (`rattachementPublicApi`) validée par le Président, ou par les comptes rattachés d'une entité (`EntiteComptesCard`) — `/api/auth/register` n'existe plus côté serveur, ne jamais le réintroduire.
- Référentiels d'entités (entreprises, autorités) : réutiliser `EntiteReferentielPage` (liste + CRUD conditionné aux permissions) plutôt que de dupliquer une page par type.
- Centralize announced server write restrictions per object in `certificatEditability`, `marcheEditability`, and `conventionEditability`; keep permissions separate so future server capabilities can replace status-derived checks.
- Track credit utilisation presence as unknown/none/present from the existing server query; never infer absence from a failed request, and keep admin descriptive corrections independent of initial amount-entry locks.
- DocumentGED accepts an explicit load error; callers must distinguish inaccessible market documents from a successful empty list and must clear stale documents when loading fails.
- Commission relais : pendant une prise de relais, `AuthContext` utilise l'entité représentée (`acting*`) comme `autoriteContractanteId`/`entrepriseId` du compte (`resolveEntityIds`) — aucun écran ne doit bloquer ou masquer une action « parce qu'en relais », le serveur décide.
- Modification de convention : afficher l'action uniquement via `canEditConvention` (`conventionEditability`, drapeau administration Président/admin) et passer par `ConventionEditDialog` (liste et fiche) — la permission seule ne suffit pas (DGB, autorité tierce) ; le corps PUT est un remplacement complet construit par `buildUpdateConventionRequest`.
- Liens multiples (autorités et bailleurs d'une convention, conventions d'un marché) : lire via `conventionAutorites` / `conventionBailleurs` / `marcheConventionIds` (ordre serveur, principal en tête, repli sur le champ simple) ; le premier élément choisi est envoyé comme principal (`OrderedMultiSelect`). Créer une convention uniquement via `ConventionCreateDialog` (liste et création à la volée depuis un marché), un bailleur via `BailleurFormDialog`.
- Annulation de convention : le chemin vient de `conventionCancelMode` (`conventionEditability`) et passe par `ConventionCancelDialog` (liste et fiche) — l'autorité titulaire/créatrice utilise `POST /annuler`, l'administration la route de statut ; ne jamais ouvrir la route de statut aux autorités (elle accepte n'importe quel statut cible). En modification, `conventionDateError` ne contrôle que les dates changées.
- Exigences documentaires : `documentRequirementApi.getByProcessus` écarte les pièces `actif: false` pour tous les écrans métier ; seul l'écran de configuration GED utilise `getConfiguration` (pièces désactivées incluses) — ne pas refiltrer dans les pages.
- Visa d'une direction sur une demande de correction : passer par `CorrectionVisaDialog` (liste, fiche, page d'évaluation) — document pré-visa et saisie des crédits retenus viennent de `GET /visas` (`codeDocumentRequis`, `saisieMontantsExigee`) relu à chaque ouverture via `useCorrectionVisaState`, jamais déduits des montants ; le corps vient de `buildCorrectionDecisionBody` (crédits seulement avec le VISA qui les exige).
- Ouverture/téléchargement de documents : passer par `openDocument`/`downloadDocument` (`src/lib/openDocument.ts`) et, pour un bouton, `DocumentButton` ; une génération de PDF passe par `trackDocumentTask` — le registre alimente l'attente globale sur la page courante (`DocumentTaskIndicator`) et l'anti double-clic ; l'onglet du fichier ne s'ouvre qu'à sa réception ; ne plus écrire `<a href={chemin}>` ni `window.open(url)` vers un fichier serveur.
- Police des documents générés : passer par `src/lib/pdfFonts.ts` (`applyOfficialFont` juste après `new jsPDF`, `PDF_FONT` dans `setFont` et les styles autoTable, `loadOfficialWebFonts` avant un rendu canvas) — ne jamais écrire un nom de police en dur dans un générateur PDF.
- Pièces réclamées en rejet temporaire : passer par `GedPiecesChecklist` / `useGedPieces(processus)` (pièces actives de la GED, code `codeDocument`, libellé GED) — le serveur refuse toute pièce non paramétrée, ne jamais revenir à une liste écrite en dur ni ajouter de liste de repli.
- Numéro de ligne des listes : `RowNumberHead` / `RowNumberCell` (`src/components/ui/row-number.tsx`) en première colonne, `n = offset de la page + index + 1` ; penser au `colSpan` des lignes vides/chargement.
